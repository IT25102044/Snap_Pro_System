# Snap Pro System

**A Java-based application developed using Spring Boot and MySQL.**

## 📌 Project Overview

Snap Pro System is a software development project built to provide a structured and maintainable backend application using modern Java technologies.

The project uses Spring Boot to develop web application functionality, Spring Data JPA for database operations, and MySQL for data storage.

## 🚀 Technology Stack

The following technologies and tools are used in this project:

| Technology | Purpose |
|---|---|
| Java 21 | Main programming language |
| Spring Boot | Backend application development |
| Spring Web MVC | Web request handling |
| Spring Data JPA | Database interaction |
| MySQL | Relational database |
| Hibernate / JPA | Object-relational mapping |
| Maven | Dependency management and build automation |
| Lombok | Reducing boilerplate Java code |
| ModelMapper | Object mapping |
| Spring Validation | Input validation |
| Spring Mail | Email functionality |

## ⚙️ Getting Started

Follow these instructions to get the project running locally.

### Prerequisites

Make sure you have installed:

- Java Development Kit (JDK) 21
- MySQL Server
- Git
- An IDE such as IntelliJ IDEA or Eclipse

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/IT25102044/Snap_Pro_System.git
```

**2. Navigate to the project directory**

```bash
cd Snap_Pro_System
```

**3. Configure the database**

Configure your MySQL database connection in the Spring Boot application configuration file.

Add the required database URL, username, password, and other necessary settings.

**4. Run the application**

For Windows:

```bash
mvnw.cmd spring-boot:run
```

For macOS/Linux:

```bash
./mvnw spring-boot:run
```

## 🧪 Testing

The project includes Spring Boot testing dependencies.

Run the available tests using:

```bash
./mvnw test
```
